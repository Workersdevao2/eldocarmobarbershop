# Eldo Carmo Barber Shop — eldocarmobarbershop.com

Full men's site with services, mini-bar products, cart → WhatsApp, gallery and Lubango recruitment.

## Key features
- Client-side cart (localStorage)
- Checkout generates pre-filled WhatsApp message to +244 923 929 074
- Contact form → WhatsApp
- Lubango recruitment section → +244 924 071 971

## Deploy
Push this folder to its own GitHub repo → connect to Cloudflare Pages (Framework: None, Output: `/`).
